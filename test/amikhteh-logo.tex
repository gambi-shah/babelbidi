% Automatic dimension checks. Allow for PGF coordinate rounding.
% Failures produce a TeX error; successful checks appear in the log.
\newsavebox{\LogoTestBox}
\newdimen\LogoTestDelta
\newcommand*\CheckDimension[3]{%
  \LogoTestDelta=\dimexpr#1-#2\relax
  \ifdim\LogoTestDelta<0pt
    \LogoTestDelta=-\LogoTestDelta
  \fi
  \ifdim\LogoTestDelta>.1pt
    \PackageError{amikhteh-logo-test}{#3 failed}%
      {The measured dimension differs from the expected value by more than 0.1pt.}%
  \else
    \typeout{AMIKHTEH LOGO TEST PASS: #3}%
  \fi
}

\section*{5. Scoped defaults and per-command overrides}

\begingroup
  \AmikhtehLogoSetup{
    size=12mm,
    primary=purple,
    accent=orange,
    name-font=\sffamily\bfseries\large,
    name-gap=3mm
  }
  \AmikhtehLogoName{Scoped defaults}\par
  \AmikhtehLogoName[primary=AmikhtehLogoBlue]{Local override}\par
  \AmikhtehLogoName{Scoped defaults again}
\endgroup
\par
\AmikhtehLogoName[size=12mm]{Original defaults restored}

  \AmikhtehLogo % Still purple and orange.

\AmikhtehLogo % Original defaults restored.
\end{verbatim}

\section*{6. Baseline alignment}

% Zero depth prevents the rules from inheriting a running depth.
Bottom:\quad
\vrule width 12mm height .2pt depth 0pt
\AmikhtehLogo[size=12mm,baseline=bottom]%
\vrule width 12mm height .2pt depth 0pt
\qquad
Centre:\quad
\vrule width 12mm height .2pt depth 0pt
\AmikhtehLogo[size=12mm,baseline=center]%
\vrule width 12mm height .2pt depth 0pt

The rules indicate the text baseline. Name lockups always use
centre alignment, independently of the \texttt{baseline} setting.

\section*{7. Local left-to-right isolation}

% Exercise direction isolation without loading a language package.
\ifXeTeX
  \begingroup
    \TeXXeTstate=1
    \hbox{\beginR\AmikhtehLogoName[size=12mm]{BabelBidi}\endR}
  \endgroup
\else\ifLuaTeX
  \hbox dir TRT {\AmikhtehLogoName[size=12mm]{BabelBidi}}
\else
  \AmikhtehLogoName[size=12mm]{BabelBidi}
\fi\fi

With XeLaTeX or LuaLaTeX, the preceding lockup is placed in an RTL
container. The mark should remain unmirrored, with its name on the right.
This is a low-level smoke test, not a full BabelBidi integration test.

\section*{8. Automatic checks}

\sbox{\LogoTestBox}{\AmikhtehLogo[size=12mm,baseline=bottom]}
\CheckDimension{\wd\LogoTestBox}{12mm}{Square width}
\CheckDimension{\ht\LogoTestBox+\dp\LogoTestBox}{12mm}{Square total height}
\CheckDimension{\dp\LogoTestBox}{0pt}{Bottom baseline depth}

\sbox{\LogoTestBox}{\AmikhtehLogo[size=12mm,baseline=center]}
\CheckDimension{\ht\LogoTestBox}{6mm}{Centre baseline height}
\CheckDimension{\dp\LogoTestBox}{6mm}{Centre baseline depth}

% An override must not change the next occurrence's default size.
\begingroup
  \AmikhtehLogoSetup{size=14mm}
  \sbox{\LogoTestBox}{\AmikhtehLogo[size=9mm]}
  \CheckDimension{\wd\LogoTestBox}{9mm}{Per-command size override}
  \sbox{\LogoTestBox}{\AmikhtehLogo}
  \CheckDimension{\wd\LogoTestBox}{14mm}{Override does not leak}
\endgroup
\sbox{\LogoTestBox}{\AmikhtehLogo}
\CheckDimension{\wd\LogoTestBox}{20mm}{Grouped setup does not leak}

If compilation finishes without errors, the automatic checks have passed.
Search the log for \texttt{AMIKHTEH LOGO TEST PASS} (eight dimension
checks and one load-isolation check).
Visual inspection of the examples is still necessary.
