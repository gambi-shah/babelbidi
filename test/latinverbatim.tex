\section*{آزمون رابط‌های لاتین برای متن کد}
در این نمونه، زبان لاتین انگلیسی، زبان چپ‌به‌راست آلمانی و زبان کد
فرانسوی است تا تفاوت انتخاب‌ها دیده شود.

\subsection*{رابط‌های فعلی}
زبان متن حفظ می‌شود و قلم لاتین از انگلیسی انتخاب می‌شود:

\verb|print("سلام") # JetBrains Mono|

\verb*|a = 1|

\begin{verbatim}
print("سلام") # JetBrains Mono
\end{verbatim}

\subsection*{رابط‌های جدید با پیشوند لاتین}
زبان کد و قلم تک‌عرض آن از فرانسوی انتخاب می‌شوند:

\latinverb|print("سلام") # Source Code Pro|

\latinverb*|a = 1|

\begin{latinverbatim}
print("سلام") # Source Code Pro
\end{latinverbatim}
\begin{latinverbatim*}
a = 1
\end{latinverbatim*}

\subsection*{هماهنگی با سایر رابط‌های کد}
\mintinline{text}|print("سلام") # Source Code Pro|

\generatedinline|x = 1 # Source Code Pro|

\begin{minted}{text}
print("سلام") # Source Code Pro
\end{minted}

این متن پس از پایان کد، دوباره فارسی و راست‌به‌چپ است.
